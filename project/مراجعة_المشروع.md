## 🔷 القسم الأول: Enum - BookCategory

**س: ما هو الـ Enum وما الفرق بينه وبين الـ Class؟**
> الـ Enum هو نوع بيانات خاص يحتوي على مجموعة ثابتة من القيم المسماة. الفرق أن الـ Class يحتوي على خصائص وطرق وبيانات متغيرة، بينما الـ Enum يُستخدم فقط لتمثيل خيارات ثابتة محدودة.

---

**س: ما هي قيم الـ Enum المستخدمة في المشروع؟**
> ```csharp
> public enum BookCategory
> {
>     Fiction, Science, History, Religion, Technology, Other
> }
> ```

---

**س: كيف نستخدم الـ Enum في الكود؟**
> ```csharp
> BookCategory cat = BookCategory.Fiction;
> ```

---

**س: ما هي قيمة الـ Enum الافتراضية إذا لم نحددها؟**
> القيمة الافتراضية تبدأ من `0`، أي أن `Fiction = 0`, `Science = 1`, `History = 2`... إلخ.

---

**س: كيف نحوّل نص (string) إلى قيمة Enum؟**
> ```csharp
> BookCategory cat = (BookCategory)Enum.Parse(typeof(BookCategory), "Fiction");
> // أو بطريقة أكثر أماناً:
> Enum.TryParse<BookCategory>("Fiction", true, out BookCategory result);
> ```

## 🔷 القسم الثاني: Class - Book

**س: ما هي خصائص كلاس Book؟**
> | الخاصية | النوع | الوصف |
> |---------|-------|-------|
> | ID | int | رقم تعريف الكتاب |
> | Title | string | عنوان الكتاب |
> | Author | string | اسم المؤلف |
> | Category | BookCategory | تصنيف الكتاب |
> | IsAvailable | bool | هل الكتاب متاح؟ |

---

**س: ما هو الـ Constructor المستخدم في كلاس Book؟**
> ```csharp
> public Book(int id, string title, string author, BookCategory category, bool isAvailable = true)
> ```
> لاحظ أن `isAvailable` لها قيمة افتراضية `true`.

---

**س: ما هي الميثود DisplayInfo() وماذا تفعل؟**
> تطبع معلومات الكتاب كاملة على الشاشة:
> ```csharp
> public void DisplayInfo()
> {
>     Console.WriteLine($"ID: {ID}");
>     Console.WriteLine($"Title: {Title}");
>     Console.WriteLine($"Author: {Author}");
>     Console.WriteLine($"Category: {Category}");
>     Console.WriteLine($"Status: {(IsAvailable ? "Available" : "Not Available")}");
> }
> ```

---

**س: ما هي الميثود UpdateStatus() وكيف تعمل؟**
> تغيّر حالة الكتاب (متاح / غير متاح):
> ```csharp
> public void UpdateStatus(bool isAvailable)
> {
>     IsAvailable = isAvailable;
> }
> ```

---

**س: ما هو الفرق بين `get` و `set` في الخصائص (Properties)؟**
> - `get`: يُستخدم لقراءة قيمة الخاصية.
> - `set`: يُستخدم لتعديل قيمة الخاصية.
> ```csharp
> public string Title { get; set; }
> ```

---

**س: ماذا تفعل override ToString() في كلاس Book؟**
> تحوّل بيانات الكتاب إلى نص مفصول بفاصلة لحفظه في الملف:
> ```csharp
> public override string ToString()
> {
>     return $"{ID},{Title},{Author},{Category},{IsAvailable}";
> }
> ```

## 🔷 القسم الثالث: File Handling - BookFileHandler

**س: لماذا استخدمنا `static` في كلاس BookFileHandler؟**
> لأنه لا نحتاج إلى إنشاء object منه، نستدعي ميثوداته مباشرة:
> ```csharp
> BookFileHandler.SaveBooks(books);
> BookFileHandler.LoadBooks();
> ```

---

**س: كيف تعمل ميثود SaveBooks؟**
> تفتح ملف نصي وتكتب فيه كل كتاب على سطر باستخدام `StreamWriter`:
> ```csharp
> using (StreamWriter writer = new StreamWriter("books.txt"))
> {
>     foreach (Book book in books)
>         writer.WriteLine(book.ToString());
> }
> ```

---

**س: ما فائدة استخدام `using` مع StreamWriter؟**
> يضمن إغلاق الملف وتحرير الذاكرة تلقائياً بعد الانتهاء، حتى لو حدث خطأ.

---

**س: كيف تعمل ميثود LoadBooks؟**
> تقرأ كل سطر من الملف، تقسمه بالفاصلة، ثم تنشئ كائن Book من البيانات:
> ```csharp
> string[] parts = line.Split(',');
> int id = int.Parse(parts[0]);
> BookCategory cat = (BookCategory)Enum.Parse(typeof(BookCategory), parts[3]);
> bool isAvailable = bool.Parse(parts[4]);
> ```

---

**س: ماذا يحدث إذا لم يكن ملف books.txt موجوداً عند محاولة التحميل؟**
> يتحقق الكود من وجود الملف أولاً، وإن لم يجده يرجع مصفوفة فارغة:
> ```csharp
> if (!File.Exists(FilePath))
>     return Array.Empty<Book>();
> ```

## 🔷 القسم الرابع: Array of Books

**س: كيف تم تعريف مصفوفة الكتب؟**
> ```csharp
> Book[] books = new Book[]
> {
>     new Book(1, "The Great Gatsby", "F. Scott Fitzgerald", BookCategory.Fiction, true),
>     // ...
> };
> ```

---

**س: كم عدد الكتب في المصفوفة وكيف يتم البحث فيها؟**
> 15 كتاب. البحث يتم بالمرور على كل عناصر المصفوفة باستخدام `foreach`:
> ```csharp
> foreach (Book book in books)
> {
>     if (book.Title.Contains(query, StringComparison.OrdinalIgnoreCase))
>         book.DisplayInfo();
> }
> ```

---

**س: ما الفرق بين `Array` و `List` في C#؟**
> | Array | List |
> |-------|------|
> | حجم ثابت | حجم ديناميكي |
> | أسرع في الوصول | أسهل في الإضافة والحذف |
> | `Book[] arr` | `List<Book> list` |

---

**س: لماذا استخدمنا `StringComparison.OrdinalIgnoreCase` في البحث؟**
> لجعل البحث غير حساس لحالة الأحرف (Capital/Small)، مثلاً "gatsby" تجد "Gatsby".

## 🔷 القسم الخامس: Program.cs - القائمة الرئيسية

**س: ما هو الـ Loop المستخدم في القائمة الرئيسية؟**
> حلقة `while` تستمر حتى يختار المستخدم الخروج:
> ```csharp
> bool running = true;
> while (running)
> {
>     // عرض القائمة وقراءة الاختيار
> }
> ```

---

**س: ما هو الـ switch statement وكيف استُخدم؟**
> يستخدم للتحقق من اختيار المستخدم وتنفيذ الأمر المناسب:
> ```csharp
> switch (input)
> {
>     case "1": // عرض الكتب
>     case "2": // بحث بالعنوان
>     case "0": running = false; break;
>     default: Console.WriteLine("Invalid option");
> }
> ```

---

**س: ما الفرق بين `int.Parse()` و `int.TryParse()`؟**
> - `int.Parse()`: يرمي Exception إذا فشل التحويل.
> - `int.TryParse()`: يرجع `true/false` ولا يرمي Exception، وهو أكثر أماناً.
> ```csharp
> if (int.TryParse(Console.ReadLine(), out int id))
> { /* نجح */ }
> ```

## 🔷 القسم السادس: مفاهيم C# عامة

**س: ما هو الـ namespace وما فائدته؟**
> ينظم الكود ويمنع تعارض الأسماء. في المشروع كل الكلاسات تحت:
> ```csharp
> namespace LibrarySystem { }
> ```

---

**س: ما الفرق بين `public` و `private`؟**
> - `public`: يمكن الوصول إليه من أي مكان.
> - `private`: يمكن الوصول إليه فقط من داخل نفس الكلاس.

---

**س: ما هو الـ String Interpolation وكيف يُستخدم؟**
> طريقة لدمج المتغيرات داخل النصوص باستخدام `$`:
> ```csharp
> Console.WriteLine($"Title: {Title}");
> ```

---

**س: ما هو الـ Ternary Operator المستخدم في المشروع؟**
> ```csharp
> IsAvailable ? "Available" : "Not Available"
> ```
> يعني: إذا كانت `IsAvailable` تساوي true اطبع "Available" وإلا اطبع "Not Available".
